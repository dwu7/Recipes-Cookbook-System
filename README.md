# Recipes Cookbook System

A relational database project developed using Oracle SQL to manage recipes, ingredients, cooking steps, meal types, and cooking tags.

## Features

- Recipe and ingredient management
- Cooking instructions and serving sizes
- Recipe filtering by cooking time and difficulty
- Meal type classification
- Cooking tag management
- Data retrieval, updates, and deletion

## Database Design

The database consists of eight related tables with primary keys, foreign keys, composite keys, and integrity constraints.

## SQL Concepts Used

- DDL and DML
- Primary and Foreign Keys
- JOIN and LEFT JOIN
- GROUP BY and HAVING
- Aggregate Functions
- Subqueries
- MINUS
- UPDATE and DELETE

## Technologies

- Oracle Database
- Oracle SQL
- SQL Developer

## Project Type

Academic group project developed as part of a Database Systems course.
